# Daftar Tangkapan Layar

Folder ini sengaja menyimpan `.gitkeep` sampai tangkapan layar aktual ditambahkan.

Nama file yang disarankan:

1. `homepage.png` — beranda desktop.
2. `about.png` — halaman Tentang.
3. `services.png` — daftar layanan.
4. `projects-map.png` — proyek mode Peta.
5. `article-detail.png` — detail artikel dengan daftar isi.
6. `contact.png` — halaman Kontak dengan form konsultasi.
7. `admin-dashboard.png` — dashboard CMS.
8. `admin-project-form.png` — form proyek admin.

Gunakan viewport minimal 1440 px untuk desktop dan satu gambar 375 px untuk responsive mobile. Jangan memasukkan data pelanggan, token, atau password ke screenshot.
